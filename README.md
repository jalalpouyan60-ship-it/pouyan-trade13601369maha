# Pouyan Trade PRO
نسخه حرفه‌ای و موبایل‌پسند داشبورد DOGE/USDT.
داده قیمت، کندل و Order Book از API عمومی Binance گرفته می‌شود. RSI، Stochastic، MACD، EMAهای 9/20/50/100/200 و ATR داخل مرورگر محاسبه می‌شوند.
فایل‌ها را در یک GitHub Repository قرار دهید و GitHub Pages را فعال کنید.
توجه: این ابزار توصیه مالی قطعی نیست و بخش «معامله‌گران بزرگ» هویت افراد را ادعا نمی‌کند؛ سفارش‌های بزرگ Order Book را نمایش می‌دهد.
